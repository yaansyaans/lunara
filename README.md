# Lunara

![Lunara](github/Screenshot.png)

<p align="center">
Lunara is a Web-Proxy UBG website that's built on [yaansyaans/anariav3](https://github.com/yaansyaans/anairav3) and fixes some old bugs and adds a all new look to the proxy world. Fast browsing, Cloudsync, Games, Cloud Gaming, Customization, Clean User Interface, and much more!

# Self-Hosting

Self hosting Lunara is simple and easy.

```sh
#Clone the repository
git clone https://github.com/yaansyaans/lunara

#Enter Directory
cd lunara


npm install       #Node install script
node server.js    #Simple node server set
```
